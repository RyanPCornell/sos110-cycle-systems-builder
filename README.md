# Cycle Systems Builder · SOS 110 In-Class Review Assignment 2

Map one biogeochemical cycle (nitrogen, phosphorus, carbon, water or oxygen) as a
system: stocks, flows between them, the conditions and human impacts that speed or
slow those flows, and the feedback loops they make.

**Live:** https://ryanpcornell.github.io/sos110-cycle-systems-builder/

- **Save** downloads a `.cycle.json` file; **Open** reads it back on any computer.
  Work also autosaves in the browser as it changes.
- **Run the model** plays the diagram forward and compares every pool with and
  without the human impacts (a qualitative sketch, not a measurement).
- **Save as PDF** prints the assignment's three sections: Title, Diagram, Summary.

Nothing is uploaded anywhere. Built from `_deck-builder/review2_cycle_builder.py`
via `review2_cycle_builder_standalone.py`; the same tool is the last slide of
https://ryanpcornell.github.io/sos110-review-assignment-2/.
